# Datasets (no manual labeling needed)

## Pothole / road damage
- Pothole Detection (2475 imgs, pretrained model also available on the page): https://universe.roboflow.com/project-yjhi5/pothole-detection-bqu6s-dwjbo
- Pothole Kaggle dataset (1718 imgs): https://universe.roboflow.com/pothole-vsmtu/kaggle_pothole
- Public Roboflow Pothole dataset (665 imgs): https://public.roboflow.com/object-detection/pothole
- Indian Driving Dataset (IDD) — Indian road scenes, useful for context/signage: https://idd.insaan.iiit.ac.in/

## Vehicle detection (no download needed — use pretrained COCO weights)
- COCO dataset classes already include car/bus/truck/motorbike/person: https://cocodataset.org/#home
- Just use `yolov8n.pt` pretrained — Ultralytics auto-downloads it, no dataset download required.

## License plates (India-specific)
- Indian Car & Bike Number Plate: https://universe.roboflow.com/indiannumberplatesdetection/indian-car-bike-number-plate
- Indian Number Plates (Kaggle): https://www.kaggle.com/datasets/dataclusterlabs/indian-number-plates-dataset
- Indian License Plates with labels (Kaggle): https://www.kaggle.com/datasets/kedarsai/indian-license-plates-with-labels

## Sample dashcam-style video (for the pipeline demo)
Search YouTube/Pexels/Kaggle for "India dashcam driving" or "traffic road India" clips — download a short 1-2 min clip to use as your "bus camera feed" stand-in. Keep it under ~2 minutes so the live demo doesn't drag.

## General search hub
- Roboflow Universe (search for waterlogging, zebra crossing, damaged signboards, etc.): https://universe.roboflow.com/
